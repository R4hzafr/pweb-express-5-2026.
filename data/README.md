# Dataset MLBB

Folder ini harus berisi dua file dataset asli dari link Google Drive yang tercantum pada halaman 4–5 modul praktikum:

- `heroes.json` — 133 hero, dari Miya sampai Hirara.
- `skins.json` — 892 skin.

Unduh dataset dari:
https://drive.google.com/file/d/1pwBUD6HnjybfGc4sobwSDYF7myHA7rW3/view?usp=sharing

Simpan kedua file langsung di folder `data/`, sehingga path akhirnya menjadi `data/heroes.json` dan `data/skins.json`.

Jangan mengganti nama properti sumber yang digunakan seed: `name`, `primaryRole`, `primaryLane`, `releaseYear`, `priceBP`, `priceDiamond` untuk hero; serta `name`, `heroId`, `rarity`, `priceDiamond` untuk skin.
